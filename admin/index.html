GitHub সংযোগ

এই তথ্য শুধু তোমার ব্রাউজারে সেভ থাকে, অন্য কোথাও পাঠানো হয় না।

Repo → Settings → Developer settings → Personal access tokens থেকে একটা টোকেন বানাও যেটার Contents: Read & Write পারমিশন আছে (classic token হলে পুরো repo scope দাও)।

এখনো কিছু টেস্ট করা হয়নি।
